# Do not use TRIBE v2 as an electorate-response model

Parallax will not use Meta TRIBE v2 to estimate voter beliefs, voting intent, demographic response, or campaign outcomes. TRIBE v2 is a research model for predicting aggregate fMRI activity from video, audio, and language stimuli, not a validated model of political opinion or population behavior. Its published repository is licensed CC BY-NC 4.0, which does not authorize this commercial product. Treating predicted neural activation as electoral response would create an unsupported scientific inference and misleading strategic output. Population-response providers must instead accept aggregate, provenance-bearing polling or consented-panel evidence, expose calibration and temporal-validation results, return uncertainty intervals, and hold terms that permit commercial deployment. The current `scenario-baseline-v1` remains a deliberately conservative observational baseline and caps confidence when representative calibration is absent.
